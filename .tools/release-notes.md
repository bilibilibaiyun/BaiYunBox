## v1.0.1 更新

### 变更
- **移除本地转录功能**：去掉 whisper.cpp / ffmpeg 引擎与「导入本地音频转录」入口，聚焦核心播放能力（点播 / 直播 / 本地视频 / 播客播放）。
- **修复 libmpv 加载路径**：libmpv-2.dll 位于 `engine/mpv/` 子目录，此前 DllImport 无法定位，现已加入 DLL 搜索路径，播放器可正常初始化。
- **安装包体积减小**：移除 whisper + ffmpeg 引擎后，安装包显著缩小。

### 保留功能
- 点播（TVBox 单线路 / FongMi 多线路源，CMS JSON）
- 直播（M3U / M3U8 / TXT）
- 本地媒体库（目录扫描、海报识别、断点续播）
- 播客（RSS / Apple 搜索订阅、下载、播放）
- 断点续播、播放控制（倍速 / 音量 / 进度 / 快捷键）
