## v1.0.2 更新

### 变更
- **点播页照搬 TVbox 经典布局**：顶部搜索框（常驻首页）+ 分类横条导航 + 海报墙网格 + 详情选集/线路切换。
- **首页改为点播主页**：打开软件即进入点播首页（TVbox 逻辑），搜索框置于首页顶部；「历史」独立成页。
- **新增「检查更新」**：设置页 → 关于，一键查询 GitHub 最新版本并提示前往下载。

### 保留功能
- 点播（TVBox 单线路 / FongMi 多线路源，CMS JSON）
- 直播（M3U / M3U8 / TXT）
- 本地媒体库（目录扫描、海报识别、断点续播）
- 播客（RSS / Apple 搜索订阅、下载、播放）
- 断点续播、播放控制（倍速 / 音量 / 进度 / 快捷键）
